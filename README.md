# Data Analytics & Machine Learning Projects

A collection of data analytics and machine learning projects covering exploratory data analysis, data cleaning, feature engineering, and model building using Python.

## Tasks

| Task | Description | Techniques |
|------|-------------|------------|
| [Task 1](./Task1_EDA_RetailSales) | Exploratory Data Analysis on Retail Sales Data | EDA, data visualization |
| [Task 2](./Task2_DataCleaning) | Data Cleaning on the Titanic Dataset | Missing value handling, outlier detection, standardization |
| [Task 3](./Task3_CustomerSegmentation) | Customer Segmentation using RFM Analysis | K-Means clustering, elbow method, RFM feature engineering |
| [Task 4](./Task4_HousePricePrediction) | House Price Prediction | Linear Regression, feature encoding |
| [Task 5](./Task5_WineQuality) | Wine Quality Prediction | Random Forest Classifier, feature importance analysis |

## Tools & Libraries
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook
